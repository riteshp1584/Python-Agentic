**Title**

LangGraph Multi-Agent Portfolio Analysis with Context Isolation and State Signature Routing

**Overview**

This script demonstrates a highly controlled multi-agent portfolio analysis system built using LangGraph, Ollama, Pydantic, and ToolNode. The workflow simulates a quantitative research team where each agent operates within a carefully isolated context to prevent reasoning contamination and recursive behavior.

A major enhancement in this version is context isolation. Each specialist agent only receives the information required for its task, preventing agents from being influenced by prior agent outputs and significantly improving workflow stability.

The architecture combines:

👑 Supervisor Agent for workflow orchestration.
🔬 Math Worker Agent for parameter extraction and tool execution.
⚙️ ToolNode Execution Engine for Sharpe Ratio calculations.
⚖️ Validator Agent for portfolio assessment.
🛡️ State Signature Tracking for deterministic workflow completion.

**Key Features**

👑 Structured Supervisor Routing using Pydantic schemas.
🔒 Context Isolation between agents to prevent cross-contamination.
🧮 Sharpe Ratio Calculation Tool with automated execution.
⚙️ ToolNode Integration for seamless tool invocation.
🚦 State Signature-Based Routing using workflow completion markers.
🔄 Loop Prevention Mechanism through explicit completion validation.
🤖 Multi-Model Architecture powered by Llama 3.1, Mistral, and Gemma 2B.
💻 Fully Local Execution using Ollama.

**Why It's Useful**

✅ Demonstrates context isolation patterns for multi-agent systems.
✅ Shows how to build state-aware supervisors.
✅ Prevents recursive reasoning and agent contamination.
✅ Implements deterministic routing using Pydantic schemas.
✅ Demonstrates automated tool execution with LangGraph.
✅ Provides a practical quantitative finance workflow.
✅ Serves as a blueprint for scalable enterprise-grade agent orchestration.
