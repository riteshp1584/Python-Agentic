**Title**

LangGraph – Conditional Entry Point Workflow

**Overview**

This script demonstrates how to build a conditional routing workflow using LangGraph. Instead of a fixed entry point, the graph uses a router function to decide which node to send the input to. Based on the content of the input text, the workflow routes to either a Finance Desk or a General Desk, then exits.

**Key Features**

🧩 Typed State Definition: Uses TypedDict to define structured state (input_text, category).

⚙️ Finance Node: Categorizes input as “Financial Services.”

📋 General Node: Categorizes input as “General Inquiry.”

🚦 Router Logic: A conditional function (route_decision) acts like a traffic cop, directing input to the correct desk.

🔗 Graph Construction: Adds nodes, sets conditional entry point, and defines exit edges.

✅ Dynamic Workflow: Demonstrates how to route inputs based on content.

**Why It’s Useful**

✅ Demonstrates conditional routing in LangGraph.

✅ Provides a dynamic entry point based on input content.

✅ Useful for classification, triage, and workflow automation.

✅ Serves as a foundation for building intelligent routers in agentic pipelines.
