**Title**

LangChain Multi-Agent Workflow with Automated Tool Execution

**Overview**

This script demonstrates how to build a multi-agent workflow using LangChain + LangGraph with automated tool execution via ToolNode. It sets up a Supervisor agent (Llama 3.1), a Math Worker agent (Mistral), and a Validator agent (Gemma 2). The Math Worker generates structured tool calls, which are automatically executed by the ToolNode. The Validator then reviews the computed Sharpe Ratio, providing a concise financial evaluation.

**Key Features**

👑 Supervisor Agent: Routes tasks between workers and ensures workflow order.

🔬 Math Worker Agent: Generates structured tool calls for Sharpe Ratio computation.

⚙️ ToolNode Integration: Automatically executes tools when invoked by the Math Worker.

⚖️ Validator Agent: Reviews the computed Sharpe Ratio and provides a one-sentence evaluation.

🧠 Team State Management: Implements a shared TeamState with message history and routing logic.

🔗 Graph Workflow: Uses StateGraph to define nodes, edges, and conditional routing.

📊 Streaming Execution: Runs the workflow step-by-step, printing outputs from each agent.

**Why It’s Useful**

✅ Demonstrates automated tool execution with ToolNode.

✅ Provides a finance-focused example of agentic workflows.

✅ Shows how to integrate tools, routing logic, and validation in LangChain.

✅ Serves as a template for building complex multi-agent systems with structured tool calls.
