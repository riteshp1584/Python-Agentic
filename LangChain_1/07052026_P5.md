**Title**

Hugging Face Transformers – Clean Text Generation Pipeline

**Overview**

This script demonstrates how to set up a Hugging Face Transformers pipeline for text generation using TinyLlama-1.1B-Chat-v1.0. It includes environment configuration, warning suppression, and clean pipeline setup with torch_dtype and cache_dir passed via model_kwargs. The example highlights how to generate Python code for financial tasks in a concise, reproducible way.

**Key Features**

⚙️ Warning Suppression: Silences Hugging Face and PyTorch warnings for cleaner console output.

🔑 Environment Setup: Loads Hugging Face cache directory (HF_HOME) from .env.

🤖 Model Integration: Uses TinyLlama-1.1B-Chat-v1.0 for text generation.

📦 Pipeline Configuration:

torch_dtype adapts to GPU/CPU availability.

cache_dir ensures models are stored in a custom directory.

device_map="auto" enables hardware-aware execution.

📝 Chat Template Usage: Applies Hugging Face’s chat template for structured prompts.

✅ Reliable Code Generation: Low temperature ensures deterministic outputs.

**Why It’s Useful**

✅ Demonstrates clean Hugging Face pipeline setup with warnings suppressed.

✅ Provides a lightweight model for reproducible code generation.

✅ Useful for quantitative finance, data science, and educational tasks.

✅ Serves as a template for scaling to larger Hugging Face models.
