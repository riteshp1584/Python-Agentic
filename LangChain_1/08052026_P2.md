**Title**

LangGraph – Minimal State Graph Example

**Overview**

This script demonstrates how to build a basic state graph workflow using LangGraph. It defines a custom GraphState, creates a single worker node to process input text, and connects the flow from entry to completion. The example highlights how to structure stateful pipelines with nodes and edges in LangGraph.

**Key Features**

🧩 Typed State Definition: Uses TypedDict to define structured state (input_text, processed_text).

⚙️ Worker Node: Processes input text and appends a message.

🔗 Graph Construction: Adds nodes, sets entry points, and defines edges.

🚀 Execution Flow: Runs the graph from initial state to final output.

✅ Minimal & Reusable: Serves as a template for building more complex workflows.

**Why It’s Useful**

✅ Demonstrates core LangGraph concepts: state, nodes, edges, and execution.

✅ Provides a minimal reproducible example for learning graph workflows.

✅ Useful as a starter template for building more advanced multi-node pipelines.

✅ Highlights how to separate state definition from processing logic.
