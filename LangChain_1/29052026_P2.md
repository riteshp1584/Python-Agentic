**Title**

LangGraph Multi-Agent Portfolio Analysis with Deterministic Exit Control and Context Isolation

**Overview**

This script demonstrates a production-oriented multi-agent portfolio analysis workflow built using LangGraph, Ollama, Pydantic, and ToolNode. The system coordinates multiple specialized AI agents to calculate and evaluate portfolio risk metrics while enforcing strict execution rules.

This version introduces a critical enhancement:

# Hard Exit Guard Logic

Rather than relying solely on LLM reasoning to determine when the workflow is complete, Python-based state checks can immediately terminate execution when all required tasks have finished. This eliminates unnecessary LLM calls and guarantees workflow completion.

The architecture combines:

👑 Supervisor Agent for orchestration.
🔬 Math Worker for tool generation.
⚙️ ToolNode for automated calculations.
⚖️ Validator Agent for portfolio review.
🛡️ Hard Exit Guard for deterministic termination.
🔒 Context Isolation for worker specialization.

**Key Features**
