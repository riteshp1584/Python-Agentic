**Title**

LangGraph – Prebuilt Agent with Gemini and Tools

**Overview**

This script demonstrates how to build a tool‑enabled agent workflow using LangGraph’s prebuilt agent constructor (create_agent) with Google Gemini (gemini-2.5-flash). Instead of manually wiring nodes and conditional edges, the prebuilt agent automatically handles tool execution, routing, and memory. The workflow integrates a custom Sharpe Ratio calculator and persists conversation history with MemorySaver.

**Key Features**

🛠️ Custom Tool: Implements a calculate_sharpe_ratio function for risk‑adjusted portfolio analysis.

🤖 Gemini Integration: Runs gemini-2.5-flash with deterministic settings (temperature=0.0).

🗂️ MemorySaver Checkpointer: Persists conversation state across multiple invocations.

🔗 Prebuilt Agent: Uses create_agent to automatically compile nodes and routing logic.

🚦 Dynamic Tool Usage: Gemini decides when to call tools versus respond directly.

✅ Streaming Execution: Displays node transitions and agent reasoning step‑by‑step.

**Why It’s Useful**

✅ Demonstrates prebuilt agent workflows with Gemini.

✅ Eliminates manual graph wiring by using create_agent.

✅ Useful for financial analysis, explainable AI, and agentic pipelines.

✅ Serves as a foundation for building scalable, tool‑enabled conversational agents.
