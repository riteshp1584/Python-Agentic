**Title**

LangGraph – Persistent Chat with Gemini and MemorySaver

**Overview**

This script demonstrates how to build a memory‑enabled conversational workflow using LangGraph with Google Gemini (gemini-2.5-flash). It defines a structured state for conversation messages, compiles the graph with a MemorySaver checkpointer, and uses a thread_id to persist dialogue history across multiple rounds. The workflow shows how Gemini can recall user details from prior interactions, enabling long‑running, context‑aware conversations.

**Key Features**

🧩 Typed State Definition: Uses TypedDict with Annotated[list[BaseMessage], add] to accumulate conversation history.

🤖 Gemini Integration: Runs gemini-2.5-flash with moderate creativity (temperature=0.3).

🗂️ MemorySaver Checkpointer: Persists conversation state across multiple invocations.

🔗 Graph Construction: Adds assistant node, sets entry point, and defines exit edges.

🧵 Threaded Conversations: Uses thread_id to maintain continuity across sessions.

✅ Context Retention: Demonstrates how Gemini remembers user details like name and profession.

**Why It’s Useful**

✅ Demonstrates persistent memory in LangGraph workflows.

✅ Provides context‑aware conversations with Gemini.

✅ Useful for research assistants, client projects, and long‑term dialogue systems.

✅ Serves as a foundation for memory‑aware agentic pipelines.
