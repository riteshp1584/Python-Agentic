**Title**

Custom Financial Calculation + Gemini Prompt Chain

**Overview**

This script demonstrates how to combine custom Python logic with Google Generative AI (Gemini) inside a LangChain pipeline. It calculates a company’s profit margin using a Python function, feeds the structured output into a prompt template, and then generates a one‑sentence financial outlook using the gemini-2.5-flash model.

It’s a clean example of mixing traditional computation with LLM reasoning in a single chain.

**Key Features**

🧮 Custom Financial Function: Computes profit margin from raw input data.

🔗 RunnableLambda Integration: Wraps Python logic into a LangChain runnable.

📝 Prompt Template: Accepts structured keys returned by the calculation function.

🤖 Gemini LLM: Generates a concise financial outlook.

📦 End-to-End Chain: Raw data → Python function → prompt → Gemini → parsed output.

**Why It’s Useful**

✅ Shows how to blend Python computation with LLM reasoning.

✅ Demonstrates structured data flow through a LangChain pipeline.

✅ Useful for financial analysis, reporting, or automated business insights.

✅ Serves as a template for more advanced hybrid pipelines (analytics → LLM → summary).
