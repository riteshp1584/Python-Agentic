**Title**

LangChain + Hugging Face – Local Model Pipeline

**Overview**

This script demonstrates how to integrate Hugging Face models into a LangChain pipeline using the HuggingFacePipeline wrapper. It authenticates with Hugging Face Hub, downloads the model, and sets up a text generation pipeline with custom parameters. The example uses TinyLlama-1.1B-Chat-v1.0, a lightweight chat model suitable for experimentation.

**Key Features**

🔑 Environment Setup: Loads Hugging Face credentials (HF_TOKEN, HF_HOME) securely from .env.

🔗 Hugging Face Hub Login: Authenticates with Hugging Face Hub for model access.

🤖 Model Integration: Uses TinyLlama/TinyLlama-1.1B-Chat-v1.0 for text generation.

⚙️ Pipeline Configuration: Customizes generation with parameters like max_new_tokens, do_sample, and repetition_penalty.

✅ LangChain Compatibility: Wraps Hugging Face models for seamless use in LangChain workflows.

**Why It’s Useful**

✅ Demonstrates Hugging Face Hub integration with LangChain.

✅ Provides a lightweight model for local experimentation.

✅ Useful for building custom pipelines with Hugging Face models.

✅ Serves as a foundation for scaling to larger models or fine-tuned tasks.
