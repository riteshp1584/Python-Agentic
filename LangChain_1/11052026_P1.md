**Title**

LangGraph – Worker + Analyzer State Graph

**Overview**

This script demonstrates how to build a multi-node state graph workflow using LangGraph. It defines a custom GraphState with multiple slots, creates two nodes (a worker and an analyzer), and connects them in sequence. The workflow shows how to process input text, hand it off between nodes, and produce structured outputs such as word counts.

**Key Features**

🧩 Typed State Definition: Uses TypedDict to define structured state (input_text, processed_text, word_count).

⚙️ Worker Node: Processes input text and appends a verification message.

📊 Analyzer Node: Counts words in the processed text.

🔗 Graph Construction: Adds nodes, sets entry points, and defines edges for sequential execution.

🖼️ ASCII Diagram: Prints a visual representation of the graph flow.

✅ Reusable Design: Template for building multi-step pipelines with LangGraph.

**Why It’s Useful**

✅ Demonstrates multi-node workflows with LangGraph.

✅ Shows how to pass state between nodes for sequential processing.

✅ Useful for text processing, analysis, and modular pipelines.

✅ Serves as a foundation for building complex agentic workflows with multiple desks/nodes.
