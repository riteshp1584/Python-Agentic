**Title**

Google Generative AI – Story Generation and Mood Analysis (Enhanced Pipeline)

**Overview**

This script demonstrates how to build a multi-output LangChain pipeline with Google Generative AI (Gemini API). It uses RunnablePassthrough to combine multiple chains into a single workflow, producing both the generated story and its mood analysis in one structured result.

**Key Features**

📝 Story Generation: Creates a short story from a given topic.

🎭 Mood Analysis: Evaluates the emotional tone of the generated story.

🔗 RunnablePassthrough Integration: Assigns outputs from multiple chains into a single dictionary.

🤖 Gemini LLM: Uses gemini-2.5-flash for both creative and analytical tasks.

✅ Multi-Output Result: Returns both story and analysis in one invocation.

**Why It’s Useful**

✅ Demonstrates multi-output pipelines with LangChain.

✅ Shows how to combine creative generation + analytical evaluation in one run.

✅ Useful for workflows that require parallel outputs (e.g., content + metadata, text + sentiment).

✅ Serves as a foundation for advanced pipelines where multiple results are needed simultaneously.
