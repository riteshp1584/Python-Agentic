**Title**

Google Generative AI – Prompt Chain Example

**Overview**

This script demonstrates how to build a LangChain pipeline with Google Generative AI (Gemini API). It uses a ChatPromptTemplate to structure system and human messages, connects them to the Gemini model, and parses the output into a clean string. The example highlights how to chain components together for flexible and reusable workflows.

**Key Features**

🔑 Environment Setup: Loads the GOOGLE_API_KEY securely from .env.

🤖 LLM Integration: Uses ChatGoogleGenerativeAI with the gemini-2.5-flash model.

📝 Prompt Template: Defines system and human roles with placeholders.

🔗 Chained Workflow: Combines prompt → LLM → output parser into a single pipeline.

✅ Error Handling: Wraps execution in a try/except block for safe runs.

**Why It’s Useful**

✅ Provides a starter template for chaining prompts with Gemini.

✅ Shows how to structure system + human roles in conversations.

✅ Useful for building assistants, Q&A systems, or structured pipelines.

✅ Serves as a foundation for more advanced multi-step LangChain workflows.
