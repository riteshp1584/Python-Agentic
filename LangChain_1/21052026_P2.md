**Title**

LangChain Multi-Agent Workflow with Dual State Slots (Messages + Metrics)

**Overview**

This script demonstrates how to build a multi-variable state workflow using LangChain + LangGraph. It introduces a custom AdvancedQuantState that maintains both conversational history (messages) and structured financial data (portfolio_metrics). The workflow consists of two specialized nodes:

A Data Extraction Node that parses raw text into structured metrics.

A Calculation Node that processes the stored metrics independently of the conversation history.

This design showcases how to separate unstructured conversation logs from structured data storage for cleaner agentic workflows.

**Key Features**

🧠 Dual State Slots: Maintains both messages (chat history) and portfolio_metrics (structured data).

🔬 Data Extraction Node: Converts messy text into clean, structured financial metrics.

⚙️ Calculation Node: Processes metrics directly from the storage slot without re-parsing text.

🔗 Graph Workflow: Uses StateGraph to define nodes, edges, and execution order.

📊 Streaming Execution: Runs the workflow step-by-step, printing outputs from each node.

**Why It’s Useful**

✅ Demonstrates multi-variable state management in LangGraph.

✅ Separates conversation history from structured data storage.

✅ Provides a finance-focused example of agentic workflows.

✅ Serves as a template for building complex pipelines where agents need both chat context and structured metrics.
