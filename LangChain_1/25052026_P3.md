**Title**

LangGraph Multi-Agent Portfolio Analysis with Structured Routing and Tool Enforcement

**Overview**

This script demonstrates an advanced multi-agent architecture built using LangGraph, Ollama, Pydantic, and ToolNode. The workflow simulates a quantitative research team where specialized AI agents collaborate to analyze portfolio performance and compute a Sharpe Ratio.

Unlike traditional supervisor patterns that rely on free-form text responses, this implementation introduces structured supervisor routing using a Pydantic schema. This guarantees predictable workflow decisions and eliminates routing errors caused by ambiguous LLM outputs.

The system combines:

👑 A Supervisor Agent that makes structured routing decisions.
🔬 A Math Worker Agent that generates tool calls.
⚙️ A Tool Execution Engine that performs mathematical calculations.
⚖️ A Validator Agent that interprets the results.

**Key Features**

👑 Structured Supervisor Decisions using Pydantic schemas.
🛠️ Sharpe Ratio Calculation Tool wrapped as a LangChain StructuredTool.
🤖 Multi-Model Architecture using Llama 3.1, Mistral, and Gemma 2B.
⚙️ Automated Tool Execution with ToolNode.
🚦 Deterministic Routing Logic enforced through structured outputs.
🔄 Dynamic Agent Orchestration with conditional graph routing.
📊 Real-Time Streaming Workflow Updates.
💻 Fully Local Execution using Ollama.

**Why It's Useful**

✅ Demonstrates enterprise-grade multi-agent orchestration.
✅ Introduces structured LLM outputs using Pydantic.
✅ Shows how to build deterministic routing systems.
✅ Demonstrates ToolNode automation for mathematical execution.
✅ Provides a real-world portfolio analysis workflow.
✅ Serves as a blueprint for building production-ready AI teams.
