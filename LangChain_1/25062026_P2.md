**Title**

LangGraph Multi-Agent Portfolio Intelligence with RAG, Memory Trimming, and Automated Optimization

**Overview**

This script demonstrates an enterprise-style multi-agent portfolio intelligence platform built using LangGraph, Ollama, Vector Search, and memory compression techniques.

Building upon the RAG-powered portfolio analysis workflow, this version introduces a significant enhancement:

Sliding Window Memory Management

As workflows become more complex, message histories can grow rapidly, increasing token usage, execution costs, and the risk of irrelevant context influencing agent decisions. To address this, the system introduces a message trimming strategy that ensures each worker only receives the most relevant portion of conversation history.

The workflow combines:

👑 Supervisory Orchestration
🔬 Quantitative Analysis
🔍 RAG-Powered Policy Retrieval
⚖️ Compliance Validation
🚀 Portfolio Optimization
🧠 Context Window Compression
📊 Structured State Management

**Key Features**

📚 Retrieval-Augmented Generation (RAG) with a vector database.
🧠 Structured Portfolio State Management using Pydantic.
✂️ Sliding Window Memory Compression using trim_messages().
🔍 Semantic Policy Retrieval via vector embeddings.
🧮 Sharpe Ratio Calculation Engine.
⚖️ Mandate-Based Compliance Analysis.
🚀 Automated Portfolio Rebalancing.
🤖 Multi-Agent Workflow Orchestration.
⚙️ ToolNode-Based Execution.
💻 Fully Local AI infrastructure powered by Ollama.
