**Title**

Local LLM – Financial Indicator Function Generator with Mistral

**Overview**

This script demonstrates how to run a LangChain pipeline with a local Ollama model (mistral:latest). It uses a prompt template to request Python functions for financial indicators, connects it to the local LLM, and parses the output into a clean string. The example highlights how to generate quant‑focused code in a structured workflow.

**Key Features**

💻 Local Model Execution: Runs mistral:latest directly on your machine via Ollama.

📝 Prompt Template: Accepts an {indicator} placeholder for flexible financial tasks.

🔗 Chained Workflow: Combines prompt → local LLM → output parser.

⚡ Deterministic Output: Uses temperature=0 for reliable, reproducible code generation.

✅ Reusable Design: Easy to adapt for different financial indicators.

**Why It’s Useful**

✅ Demonstrates local LLM integration with LangChain.

✅ Provides a deterministic workflow for generating financial code.

✅ Useful for quantitative finance, trading strategies, and risk modeling.

✅ Serves as a foundation for building quant developer assistants.
