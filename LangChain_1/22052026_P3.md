Title

LangChain Multi-Agent Team with Supervisor, Math Worker, and Validator

Overview

This script demonstrates how to build a multi-agent workflow using LangChain + LangGraph with specialized roles. It sets up a Supervisor agent (Llama 3.1), a Math Worker agent (Mistral), and a Validator agent (Gemma 2). Together, they collaborate to compute and validate the Sharpe Ratio of a portfolio, showcasing how multiple LLMs can coordinate in a structured pipeline.

Key Features

👑 Supervisor Agent: Routes tasks between workers and ensures workflow order.

🔬 Math Worker Agent: Uses a custom calculate_sharpe_ratio tool to compute risk-adjusted performance.

⚖️ Validator Agent: Evaluates the computed Sharpe Ratio and provides a concise risk assessment.

🧠 Team State Management: Implements a shared TeamState with message history and routing logic.

🔗 Graph Workflow: Uses StateGraph to define nodes, edges, and conditional routing.

📊 Streaming Execution: Runs the workflow step-by-step, printing outputs from each agent.

Why It’s Useful

✅ Demonstrates multi-agent collaboration with specialized roles.

✅ Provides a finance-focused example of agentic workflows.

✅ Shows how to integrate tools, routing logic, and validation in LangChain.

✅ Serves as a template for building complex multi-agent systems (finance, research, analytics).
