**Title**

Local LLM – Reasoning + Final Answer Separation with Gemma

**Overview**

This script demonstrates how to run a LangChain pipeline with a local Ollama model (gemma2:2b) while enabling reasoning capture. The model generates both its internal “thinking process” and the final answer, with the reasoning stored separately in additional_kwargs['reasoning_content']. This allows developers to inspect the model’s thought process without mixing it into the final output.

**Key Features**

💻 Local Model Execution: Runs gemma2:2b directly on your machine via Ollama.

🧠 Reasoning Capture: Separates the model’s internal “thinking” from the final answer.

📝 Prompt Flexibility: Accepts direct user queries without templates.

🔗 Structured Output: Provides both reasoning logs and clean final content.

✅ Useful for Debugging: Helps analyze how the model arrives at its conclusions.

**Why It’s Useful**

✅ Demonstrates reasoning-enabled workflows with LangChain + Ollama.

✅ Provides transparency into the model’s thought process.

✅ Useful for financial analysis, debugging, and research applications.

✅ Serves as a foundation for building explainable AI pipelines.
