**Title**

LangGraph Multi-Agent Portfolio Analysis with Automated Tool Execution

**Overview**

This script demonstrates how to build an advanced multi-agent system using LangGraph, Ollama, and ToolNode. The workflow simulates a collaborative quant research team consisting of:

👑 Supervisor Agent (Llama 3.1) for orchestration and task routing.
🔬 Math Worker Agent (Mistral) responsible for extracting portfolio metrics and generating tool calls.
⚙️ Tool Execution Engine (ToolNode) that automatically executes Python functions.
⚖️ Validator Agent (Gemma 2B) that reviews results and provides financial interpretation.

The system automatically routes work between agents, executes tools, validates results, and completes the workflow without manual intervention.

**Key Features**

🤖 Multi-Agent Architecture with specialized AI roles.
🛠️ Automated Tool Execution using LangGraph's ToolNode.
📈 Sharpe Ratio Calculation Tool for portfolio analysis.
👑 Supervisor-Controlled Workflow with dynamic routing.
🔄 Conditional Graph Navigation driven by agent decisions.
⚡ Local LLM Stack powered entirely by Ollama.
📊 Real-Time Streaming Logs showing every step of execution.

**Why It's Useful**

✅ Demonstrates true multi-agent orchestration with LangGraph.
✅ Shows how to implement specialized agent roles.
✅ Illustrates automated tool execution using ToolNode.
✅ Provides a practical quantitative finance use case.
✅ Serves as a blueprint for research assistants, portfolio analyzers, and enterprise agent systems.
✅ Highlights how supervisors can coordinate multiple AI workers in a structured workflow.
