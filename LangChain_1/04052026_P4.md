**Title**

Local LLM – Prompt Chain with Ollama

**Overview**

This script demonstrates how to run a LangChain pipeline with a local Ollama model (llama3.1). It sets up a system role, accepts user input, and generates a structured response using the local LLM. The example highlights how to integrate Ollama into LangChain for offline, cost‑free experimentation.

**Key Features**

💻 Local Model Execution: Runs llama3.1 directly on your machine via Ollama.

📝 Prompt Template: Defines system and human roles with placeholders.

🔗 Chained Workflow: Combines prompt → local LLM → output parser.

⚡ Error Handling: Provides a clear message if Ollama isn’t running.

**Why It’s Useful**

✅ Demonstrates local LLM integration with LangChain.

✅ Provides a cost‑free, offline workflow for experimentation.

✅ Useful for testing pipelines without relying on cloud APIs.

✅ Serves as a foundation for building agentic workflows with local models.
