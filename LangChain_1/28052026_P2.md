**Title**

LangGraph Multi-Agent Portfolio Analysis with State-Aware Routing and Infinite Loop Prevention

**Overview**

This script demonstrates an advanced multi-agent orchestration system built with LangGraph, Ollama, Pydantic, and ToolNode. It simulates a quantitative research team where specialized AI agents collaborate to calculate and evaluate portfolio risk metrics.

A major enhancement in this version is the introduction of state signature validation. Instead of relying on message counts or keyword matching, the supervisor directly inspects the graph state for:

Presence of actual tool execution results (ToolMessage)
Presence of completed validator reviews (AIMessage)
Structured routing decisions enforced through Pydantic schemas

This approach eliminates accidental routing errors and prevents infinite execution loops.

**Key Features**

👑 State-Aware Supervisor Agent using graph message signatures.
🧮 Sharpe Ratio Calculation Tool with automated execution.
🤖 Specialized Multi-Agent Team powered by Ollama.
⚙️ ToolNode Integration for automatic tool processing.
🔄 Infinite Loop Prevention through workflow completion checks.
📊 Structured Routing using Pydantic schemas.
💻 Fully Local Execution with Ollama models.
🚀 Real-Time Streaming Workflow Visualization.
