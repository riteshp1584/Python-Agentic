**Title**

LangGraph – Human Worker + LLM Analyzer

**Overview**

This script demonstrates how to build a hybrid state graph workflow using LangGraph and a local Ollama LLM (Mistral). It defines a structured state, creates two nodes (a human-coded worker and an LLM agent), and connects them in sequence. The workflow shows how to process input text with deterministic logic, then hand it off to an LLM for deeper analysis.

**Key Features**

🧩 Typed State Definition: Uses TypedDict to define structured state (input_text, processed_text, word_count).

⚙️ Worker Node: Adds a verification signature to the input text.

🤖 LLM Agent Node: Uses Mistral (mistral:latest) to count words and explain the reasoning.

🔗 Graph Construction: Adds nodes, sets entry points, and defines edges for sequential execution.

🚀 Hybrid Workflow: Combines deterministic Python logic with LLM reasoning.

✅ Reusable Design: Template for building multi-step pipelines where human-coded logic and AI agents collaborate.

**Why It’s Useful**

✅ Demonstrates hybrid workflows combining Python logic + LLM reasoning.

✅ Provides transparent analysis by showing both deterministic and AI-driven steps.

✅ Useful for quantitative finance, text analysis, and explainable AI pipelines.

✅ Serves as a foundation for building agentic systems where human-coded nodes collaborate with LLM agents.
