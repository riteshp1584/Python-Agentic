**Title**

LangGraph – Gemini Agent with Tool Routing

**Overview**

This script demonstrates how to build a tool‑enabled agent workflow using LangGraph with Google Gemini (gemini-2.5-flash). It defines a structured state for conversation messages, registers a custom financial tool (Sharpe Ratio calculator), and connects nodes with conditional routing. The workflow allows Gemini to decide when to call tools versus when to respond directly, creating a dynamic loop between the assistant and tool execution.

**Key Features**

🧩 Typed State Definition: Uses TypedDict with Annotated[list[BaseMessage], add] to accumulate conversation history.

🛠️ Custom Tool: Implements a calculate_sharpe_ratio function for risk‑adjusted portfolio analysis.

🤖 Gemini Integration: Initializes Gemini with tool binding for permission‑aware execution.

🔗 Graph Construction: Adds assistant and tool nodes, sets entry point, and defines conditional routing.

🚦 Dynamic Routing: Uses tools_condition to decide whether Gemini’s response requires tool execution or direct output.

🔄 Looping Workflow: Routes back to the assistant after tool execution for seamless conversation.

✅ Streaming Execution: Displays node transitions in real‑time for transparency.

**Why It’s Useful**

✅ Demonstrates tool‑enabled agent workflows with Gemini.

✅ Provides dynamic routing between assistant and tools.

✅ Useful for financial analysis, explainable AI, and agentic pipelines.

✅ Serves as a foundation for building multi‑tool, multi‑node conversational agents.
