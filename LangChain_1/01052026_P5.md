**Title**

Simple Prompt Generator Utility

**Overview**

This script defines a lightweight helper function generate_prompt that creates concise prompts for question answering. It optionally incorporates contextual information into the prompt, making it flexible for different use cases such as knowledge retrieval or LLM-based Q&A.

**Key Features**

📝 Dynamic Prompt Creation: Generates a clean, structured prompt string.

⚡ Optional Context Support: Adds background information when provided.

✅ Minimal & Reusable: Easy to integrate into larger workflows.

**Why It’s Useful**

✅ Provides a starter template for prompt engineering.

✅ Helps structure queries for LLMs or Q&A systems.

✅ Serves as a foundation for building more advanced prompt pipelines.
