**Title**

LangGraph Multi-Agent Portfolio Analysis with Structured Routing and Execution Tracking

**Overview**

This script demonstrates a sophisticated multi-agent financial analysis system built using LangGraph, Ollama, Pydantic, and ToolNode. The workflow simulates a collaborative quant research team where agents perform calculations, validate results, and coordinate through a supervisor that makes decisions based on actual execution history.

A key enhancement in this version is the supervisor's ability to track:

Tool execution counts
Validator completion status
AI-generated review messages

Instead of simply searching for keywords in conversation logs, the supervisor examines the graph state and makes routing decisions using measurable execution metrics, creating a more reliable and production-ready orchestration pattern.

**Key Features**

👑 Execution-Aware Supervisor Agent using structured outputs.
🧮 Sharpe Ratio Calculation Tool for portfolio evaluation.
🤖 Three Specialized Local Models with dedicated responsibilities.
⚙️ Automated Tool Execution via LangGraph ToolNode.
📊 State-Based Workflow Control using message counts.
🔄 Deterministic Multi-Agent Orchestration.
🏗️ Pydantic Structured Routing for predictable supervisor decisions.
💻 Fully Local AI Stack powered by Ollama.

**Why It's Useful**

✅ Demonstrates execution-aware multi-agent orchestration.
✅ Shows how supervisors can make decisions based on actual workflow state.
✅ Introduces structured outputs with Pydantic.
✅ Eliminates fragile keyword-matching routing logic.
✅ Demonstrates automated tool execution using LangGraph's ToolNode.
✅ Provides a realistic quantitative portfolio analysis workflow.
✅ Serves as a blueprint for enterprise-grade AI orchestration systems.
