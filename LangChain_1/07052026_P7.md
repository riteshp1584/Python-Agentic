**Title**

Local LLM – Structured Prompt Chain for Financial Factors

**Overview**

This script demonstrates how to run a LangChain pipeline with a local Ollama model (mistral). It uses a structured ChatPromptTemplate with system and human roles to request Python functions for financial indicators. The chain ensures clean, reproducible outputs by setting temperature=0 and parsing results into plain strings.

**Key Features**

💻 Local Model Execution: Runs mistral directly on your machine via Ollama.

📝 Role-Based Prompting: Separates system instructions (expert persona) from human queries.

🔗 Chained Workflow: Input dictionary → prompt → LLM → string output.

⚡ Deterministic Output: Uses temperature=0 for consistent, non‑creative code.

✅ Reusable Design: Modular chain for generating different financial factor functions.

**Why It’s Useful**

✅ Demonstrates structured prompting with system + human roles.

✅ Provides clean, deterministic code generation for quant workflows.

✅ Useful for trading strategies, risk modeling, and financial analysis.

✅ Serves as a foundation for modular, reusable pipelines in LangChain.
