**Title**

Local LLM – High-Precision Financial Analysis with DeepSeek

**Overview**

This script demonstrates how to run a LangChain pipeline with a local Ollama model (deepseek-r1:1.5b) configured for math and financial reasoning tasks. It uses tuned parameters for precision, enables reasoning capture, and generates a structured response to financial queries such as bond price impacts.

**Key Features**

💻 Local Model Execution: Runs deepseek-r1:1.5b directly on your machine via Ollama.

⚙️ Parameter Tuning:

temperature=0.1 → reduces randomness for accurate math/finance outputs.

top_p=0.9 → focuses on the most probable tokens for coherence.

num_predict=2048 → sets maximum token output length.

🧠 Reasoning Enabled: Captures the model’s internal thought process separately.

📊 Finance-Oriented Prompt: Example query on bond price impact of interest rate changes.

**Why It’s Useful**

✅ Demonstrates precision-tuned local LLM workflows.

✅ Provides transparent reasoning for financial analysis.

✅ Useful for quantitative finance, risk modeling, and economic research.

✅ Serves as a foundation for explainable AI in capital markets.
