**Title**

LangGraph Multi-Agent Portfolio Analysis with RAG, Policy Compliance, and Automated Portfolio Optimization

**Overview**

This script demonstrates a sophisticated Retrieval-Augmented Generation (RAG) multi-agent system built using LangGraph, Ollama, Vector Search, and ToolNode.

Unlike previous portfolio analysis workflows that relied solely on calculations, this version introduces a corporate investment policy knowledge base. The AI team retrieves relevant investment mandates, validates portfolio performance against those mandates, and automatically triggers portfolio optimization when policy requirements are not met.

The workflow combines:

👑 A Supervisory Orchestrator
🔬 A Quantitative Math Agent
🔍 A RAG Policy Retrieval Agent
⚖️ A Compliance Validation Agent
🚀 An Optimization Agent
⚙️ Automated Tool Execution
📚 Vector-Based Corporate Knowledge Retrieval

**Key Features**

📚 Retrieval-Augmented Generation (RAG) using a vector database.
🧠 Structured PortfolioMetrics State Object for storing workflow facts.
🔍 Semantic Search of Investment Mandates using embeddings.
🧮 Sharpe Ratio Calculation Engine.
⚖️ Policy-Based Risk Validation.
🚀 Automated Portfolio Optimization Workflow.
🤖 Multi-Agent Collaboration with specialized responsibilities.
⚙️ ToolNode-Based Function Execution.

**Why It's Useful**

✅ Demonstrates Retrieval-Augmented Generation (RAG) inside a multi-agent system.
✅ Combines vector search, financial analytics, and AI orchestration.
✅ Shows how to build compliance-aware portfolio review systems.
✅ Uses structured state rather than chat history for decision making.
✅ Demonstrates automatic escalation from analysis → compliance review → optimization.
✅ Serves as a blueprint for institutional risk management workflows.
