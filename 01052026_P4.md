**Title**

Google Generative AI – Conversational Joke Script

**Overview**

This script demonstrates how to use Google Generative AI (Gemini API) with LangChain’s ChatGoogleGenerativeAI wrapper to run a conversational pipeline. It sets up a system role, accepts a user query, and generates a response using the Gemini 2.5 Flash model. The example highlights how to structure messages for system and human roles, making it easy to build assistants with personality and context.

**Key Features**

🔑 Environment Setup: Loads the GOOGLE_API_KEY securely from .env.

🤖 LLM Integration: Uses ChatGoogleGenerativeAI with the gemini-2.5-flash model.

📝 Role-Based Messaging: Demonstrates SystemMessage (assistant persona) and HumanMessage (user query).

🎭 Conversational Output: Generates a creative response (in this case, a joke).

**Why It’s Useful**

✅ Provides a starter template for conversational AI with Gemini.

✅ Shows how to use system and human roles for structured prompts.

✅ Useful for building assistants, chatbots, or creative content generators.

✅ Serves as a foundation for more advanced workflows (multi-turn conversations, tool integration).
